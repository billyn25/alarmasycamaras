# Auditoría SEO técnica de cierre · 9 octubre 2026

Dominio canónico fijado: https://alarmasycamarasrapid.com

## Cerrado
- Una sola URL canónica por página HTML válida; 404 sin canonical.
- Ningún canonical puede apuntar a netlify.app.
- Open Graph usa el mismo origen canónico.
- Redirecciones de http y www al dominio HTTPS sin www.
- Redirecciones de /index.html y rutas antiguas Vizcaya/Guipúzcoa a la URL limpia.
- Sitemap de producción solo admite páginas indexables.
- Robots y X-Robots-Tag mantienen noindex durante revisión.
- 3.797 páginas municipales conservan indexación escalonada: solo se indexan al aprobar su contenido local.
- Provincias requieren al menos tres municipios aprobados antes de ser indexables.
- Legal y 404 siguen fuera del sitemap.
- Títulos, descripciones, H1, imágenes, enlaces y anclas se auditan en build.
- Logo y favicon usan nombres nuevos para evitar que Safari/Netlify sirvan la versión antigua desde caché.

## Publicación
El código queda preparado para el dominio definitivo. No se fuerzan a producción NIF, domicilio, derechos de imágenes o cobertura comercial no confirmados. Estos datos no se inventan ni se muestran como pendientes al visitante.
