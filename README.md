# Cámaras y Alarmas Rapid

Web de instalaciones de alarmas inalámbricas y videovigilancia. Identidad aprobada: blanco, grafito y azul, con el logo horizontal de protección y lente.

## Estado

Primera implementación en preparación. Este repositorio no sustituye ni modifica ninguna otra web. El dominio final todavía no está definido. El despliegue de revisión debe permanecer con `noindex`.

## Alcance

- Alarmas inalámbricas de grado 2, sin cuota mensual obligatoria por el sistema autogestionado.
- Cámaras de seguridad, visión nocturna y sistemas compatibles integrados.
- Ajax, Hikvision, Dahua, Uniview, Nivian y EZVIZ.
- Una página por municipio en las 19 provincias solicitadas, no tres páginas duplicadas por servicio.
- HTML estático, navegación utilizable sin JavaScript y publicación en Netlify.

No se anuncian central receptora, aviso automático a Policía, atención 24 horas, reseñas ni acreditaciones no confirmadas. El grado y la integración dependen del equipo y la configuración; SIM, mantenimiento y nube opcionales se presupuestan aparte.
